# Assets do Nível 1 expandido

**82 modelos visuais distintos**, presentes em **1005 instâncias de cenário**.

Contagem obtida da cena montada, percorrendo as raízes dos prefabs ativos com renderizadores. Cada origem é assinada pela geometria das suas malhas. Cores, materiais, UVs, nomes, posição, rotação e escala das instâncias não entram na assinatura. Prefabs com a mesma geometria compartilham uma linha. Formatos alternativos OBJ/glTF não foram instanciados. A lista registra conjuntos de geometria dos modelos, sem contar cada submalha como outro asset. UI, jogador, textos e objetos vazios ficam fora.

Os hashes e as origens das malhas estão no JSON e CSV para conferência. A leitura de malhas usa a API do Editor [MeshUtility.AcquireReadOnlyMeshData](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/MeshUtility.AcquireReadOnlyMeshData.html), sem abrir arquivos binários manualmente.
